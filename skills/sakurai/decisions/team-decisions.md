# 責任・共有・観察

<a id="authority-or-vote"></a>
## authority-or-vote：多数決にするか、責任者が決めるか

- 問題：多数決にするか、責任者が決めるか。
- 適用状況：作品の方向を決める判断と、意見を集める作業、役割の兼任を区別する。
- 出典要約：職種間の連携、ディレクターの個性と責任、正しい情報、プロデューサーとの役割分担、協力者への敬意を扱う。
  - 出典：[team.md](../references/team.md) の 050「ゲームを作る職種」、[mindset.md](../references/mindset.md) の 070「ディレクターは”個”」、[mindset.md](../references/mindset.md) の 156「無意味な多数決」、[team.md](../references/team.md) の 232「ディレクターとプロデューサー」、[mindset.md](../references/mindset.md) の 258「上は下なり、下は上なり」。
- 判断案（編集上の解釈）：意見収集の範囲と最終決定者を明確にし、異論の情報を残して理由と結果を共有する。
- 適用外・導けないこと：責任者を根拠に異論を隠したり、ユーザーの決定権を代行したりしない。全組織の役割を同じに固定しない。
- 関連・対立：[decide-or-investigate](production.md#decide-or-investigate)、[playtest-evidence](team-decisions.md#playtest-evidence)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

<a id="communication-or-focus"></a>
## communication-or-focus：すぐ共有するか、まとめて集中時間を守るか

- 問題：すぐ共有するか、まとめて集中時間を守るか。
- 適用状況：判断待ち、監修依頼、担当間の受渡し、在宅環境、過剰な割込み。
- 出典要約：進捗と問題の共有、改善案付きの指摘、チケットでの記録、当日中の監修と集中時間の確保、在宅機材の支援を扱う。
  - 出典：[team.md](../references/team.md) の 043「チームの情報共有」、[team.md](../references/team.md) の 060「思ったことはすぐに言え」、[tech.md](../references/tech.md) の 094「チケットでタスク管理」、[team.md](../references/team.md) の 122「日報のすすめ」、[team.md](../references/team.md) の 175「その日のうちに全てこなす」、[misc.md](../references/misc.md) の 066「ソラの在宅支援策」、[mindset.md](../references/mindset.md) の 247「絶対にケンカするな」。
- 判断案（編集上の解釈）：誰が何を待つかを確認し、緊急な判断と定期共有を分ける。返信時点、記録先、集中する時間をチームに合わせる。
- 適用外・導けないこと：メールしか使わない、全員が毎日同じ日報を書く、を普遍的な規則にしない。対立を避けるため問題を隠すとも解釈しない。
- 関連・対立：[lock-or-merge](technical-decisions.md#lock-or-merge)、[scope-or-quality](production.md#scope-or-quality)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

<a id="playtest-evidence"></a>
## playtest-evidence：声の大きさを採るか、対象者の反応とデータを見るか

- 問題：声の大きさを採るか、対象者の反応とデータを見るか。
- 適用状況：開発者の慣れ、SNS の偏り、専門モニターの意見、初見プレイヤーの行動が食い違う場面。
- 出典要約：専門的な実戦分析、初見の行詰まりの観察、エコーチェンバー、開発者の慣れへの補正、初心者の入口を扱う。
  - 出典：[team.md](../references/team.md) の 218「モニタリングは果てなく続く」、[team.md](../references/team.md) の 246「小学生モニター」、[mindset.md](../references/mindset.md) の 226「エコーチェンバー」、[gameplay.md](../references/gameplay.md) の 254「ハンデをつけてバランス調整」、[planning.md](../references/planning.md) の 240「初心者にはやさしく、気持ちよく」。
- 判断案（編集上の解釈）：誰のどの場面を改善するかを決め、発言、行動、利用条件、成績を照合する。母集団と観察の限界も記録する。
- 適用外・導けないこと：子供や熟練者の反応を全対象者へ一般化しない。データがあることだけで目指す個性を消さない。
- 関連・対立：[asymmetry-or-balance](systems.md#asymmetry-or-balance)、[difficulty-or-assistance](onboarding-difficulty.md#difficulty-or-assistance)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。
