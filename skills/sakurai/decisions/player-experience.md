# プレイヤー体験と調整

## randomness-and-handicap：ランダム性と逆転補正をどの程度入れるか

- 問題：実力の反映と、実力差がある人同士の盛り上がりをどう配分するか。
- 適用状況：対戦ルールの設計。腕前を測る場か、家族・友人が混ざって遊ぶ場かで判断を分ける（出典要約に区別がある）。
- 出典要約：[specs.md](../references/specs.md) の 187「ランダム性は彩りを添える」は、鮮度・対応の幅と不公平・納得感の問題を挙げ、腕前で決めたい対戦とパーティ寄りの対戦を分ける。200「ハンデブースト」はカジュアル向けの逆転補正と、実力重視の弱い補正を区別し、家庭内の人力ハンデとオンラインの相性にも言及する。
- 判断案（編集上の解釈）：実力重視なら、運が選択肢を変えるのか勝敗を直接覆すのかを分けて検討する。混在した実力層の交流が目的なら、補正の存在を説明し、負けている側にも参加する意味があるかを見る。両方を狙う作品はルールやモードを分けることも候補にする。
- 適用外・導けないこと：対戦だからランダムを全廃、または負け側を必ず強化、とは言えない。家庭内の口約束で済む調整を、オンライン全般に広げない。モード分離は改版で加えた提案候補であり、両要約の明言ではない。
- 関連・対立：187 と 200 を比較する。恒久的な成長差には `progression-rewards`。
- 根拠の状態：AI 要約のみ・原動画未照合。

## progression-rewards：成長報酬を対戦にも使うか

- 問題：進展や収集の喜びを作りながら、対戦前の育成負担をどう扱うか。
- 適用状況：ソロ進行、対戦、または両者を持つ作品の報酬設計。
- 出典要約：[planning.md](../references/planning.md) の 149「見返りを想定する」は純粋な強化を有効な報酬として挙げる一方、対戦では育成強化が向かないとし、キャラ・音楽・モードなどの解放を代替に挙げる。[concepts.md](../references/concepts.md) の 092「そだてて!甲虫王者ムシキング」は、育成を組み合わせた対戦で強弱差による破綻に注意するとしている。
- 判断案（編集上の解釈）：ソロでは強化が次の挑戦にどう役立つかを検討する。公平な対戦を狙うなら、育成を終えるまで参加しにくくならないかを確認し、非能力系の報酬も比較する。キャラ解放も必要な選択肢を制限し得るため、公平性を個別に確認する。
- 適用外・導けないこと：149 の有効な報酬を全モードの必須仕様にしない。育成を含む対戦が成立しないと断定せず、092 の事例の条件も調べる。キャラ解放なら常に公平という保証もない。
- 関連・対立：149 の中のソロと対戦の区別、092 の事例。勝敗補正には `randomness-and-handicap`。
- 根拠の状態：AI 要約のみ・原動画未照合。キャラ解放の公平性の点検は編集上の追加判断。

## impact-and-tempo：手応えを増すか、停止と待ちを減らすか

- 問題：出来事の認識を強める演出と、入力への応答・テンポを両立する。
- 適用状況：ヒットが弱い、操作が重い、テンポが悪いという相談。何が起きた瞬間かを先に確かめる（編集上の診断方針）。
- 出典要約：[specs.md](../references/specs.md) の 003「大事なところはストップ！」は見せ場を止めて認識させるヒットストップを勧め、047「8つのヒットストップ仕様」は長さや振動の調整を扱う。073「遅さは罪」は操作のない待ち時間を詰め、箸休めとしてのイベント等を認める。244「画面遷移は素早く」は迅速さに加えて、演出がゼロだと戸惑う点を挙げる。[planning.md](../references/planning.md) の 128「3Dゲームで酔う場合」はカメラ揺れを控える対策やオプション化を挙げる。
- 判断案（編集上の解釈）：ヒットの認識不足なら短い停止や音・ポーズなどを比較する。入力応答や遷移の待ちが問題なら原因を計測し、その待ちを減らす。停止の有無・長さを比較し、認識のしやすさと操作の妨げを観察する。揺れが苦手な人向けには別の反応や設定も候補にする。
- 適用外・導けないこと：003 の強い表現だけで、見せ場のないゲームにも一律の停止を追加しない。073 を根拠に全ての間や演出を除去しない。ヒットストップが入力遅延の解決になるとは限らない。具体的な秒数・フレーム数は対象作品で検証する。
- 関連・対立：003・047 と 073・244、128。出典が明言した統一理論ではなく、目的の違いとして比較する。
- 根拠の状態：AI 要約のみ・原動画未照合。診断と比較方法は編集上の解釈。
