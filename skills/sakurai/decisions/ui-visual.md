# UI と視認性

## style-or-clarity：世界観を優先するか、分かりやすさを優先するか

- 問題：画面の個性と、目的の操作に到達できることを両立する。
- 適用状況：初見の入口、頻繁に使う操作、雰囲気を楽しむ画面など、用途ごとに判断する。
- 出典要約：[ui.md](../references/ui.md) の 018「わかりやすさとスタイル性」は目的に合わせた配分を求め、111「メニューは世界を語る」は UI とフォントによる世界観を扱う。238「言語がなくてもわかるように」は、言葉が分からなくても本編へ入れる設計を挙げる。
- 判断案（編集上の解釈）：最重要の行動を決め、その発見・選択・結果の理解を初見で観察する。世界観の表現を保ちつつ、重要度、大きさ、絵、ヘルプ等で迷いを減らす候補を比較する。
- 適用外・導けないこと：装飾の全廃も、雰囲気のための読めなさも一律には正当化できない。操作数を減らすために確認が必要な行為まで連打可能にする根拠ではない。
- 関連・対立：018・111・238。文字と画面制約は `localization-or-layout`。
- 根拠の状態：AI 要約のみ・原動画未照合。

## localization-or-layout：文字を縮めるか、レイアウトを変えるか

- 問題：複数言語・小画面で意味と視認性を維持する。
- 適用状況：翻訳による長文化、漢字の可読性、携帯モードの確認。
- 出典要約：[ui.md](../references/ui.md) の 033「文字の大きさ」は言語ごとの文字サイズと長さの違い、領域の余裕、実機確認を挙げる。145「大事なものをより大きく」は重要項目の大型化と、長い翻訳が収まらない欠点を記載。093「文字強調」は言語に合う強調を翻訳者が調整できる仕組みを勧める。
- 判断案（編集上の解釈）：最長・最短の実際の翻訳と対象画面で確認し、折返し、領域変更、短縮表現、段階的開示を比較する。文字を小さくする案は可読性と意味が保てるかを検証する。
- 適用外・導けないこと：日本語の文字数だけから全言語の拡張率を固定しない。文字数を満たすための意味の脱落や、無検証の縮小を出典の推奨としない。
- 関連・対立：033・145・093。情報の優先順位は `style-or-clarity`。
- 根拠の状態：AI 要約のみ・原動画未照合。具体的なレイアウト候補は編集上の提案。

## detail-or-readability：背景を豊かにするか、遊びの対象を目立たせるか

- 問題：見栄えと、判定・行動対象の認識を両立する。
- 適用状況：背景に埋もれる足場・敵、過密な HUD、色だけで区別する仕掛け。
- 出典要約：[graphics.md](../references/graphics.md) の 030「判定のあるものを強調する」は床・足場等と背景の区別を扱う。[planning.md](../references/planning.md) の 212「色が薄れた世界」は明度や絵柄による色覚への配慮を挙げる。[ui.md](../references/ui.md) の 252「HUD」は、量をやりやすさと面白さから決め、状況で表示を変えるとする。
- 判断案（編集上の解釈）：何を見落としたかを特定し、明度、輪郭、形、配置、情報の出し分けを比較する。静止画だけでなく実プレイ中の認識と対象端末で確認する。
- 適用外・導けないこと：全対象を同じ強さで目立たせない。色追加だけを万能な解決とせず、背景の情報全体を削る必要があるとも決めつけない。
- 関連・対立：030・212・252。世界観の維持は `style-or-clarity`。
- 根拠の状態：AI 要約のみ・原動画未照合。比較方法は編集上の解釈。
