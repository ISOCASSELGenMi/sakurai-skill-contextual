<a id="risk-reward-proximity"></a>
## risk-reward-proximity：危険と見返りをどう結び付けるか

- 問題：危険と見返りをどう結び付けるか。
- 適用状況：駆け引きが楽しさの核で、強い行動に代償がない、または危険を負っても得がない場面。
- 出典要約：危険と見返りを近くに置き、接近・隙・制御の制約と効果を結び付ける。努力と報酬・罰の釣り合いも見直す。
  - 出典：[gameplay.md](../references/gameplay.md) の 006「リスクとリターン」、[gameplay.md](../references/gameplay.md) の 065「浮遊感は落ちてこそ生まれる」、[gameplay.md](../references/gameplay.md) の 133「シューティングゲームのゲーム性」、[gameplay.md](../references/gameplay.md) の 191「アクションゲームのゲーム性」、[gameplay.md](../references/gameplay.md) の 236「どれぐらい良いことをした？」。
- 判断案（編集上の解釈）：一つの行動について危険、得る効果、安全な代替を並べ、どこで判断が生まれるか試す。
- 適用外・導けないこと：物語や操作自体を楽しむ作品に戦闘や失敗を強制しない。罰の重さだけで面白さを測らない。
- 補足出典要約：RPG の帰還判断と、落ち物の蓄積・解消という異なる駆け引きの例がある。接近戦の形をそのまま他ジャンルへ移さず、何が危険になるかを対応させる。
  - 出典：[gameplay.md](../references/gameplay.md) の 015「RPGのゲーム性」、[gameplay.md](../references/gameplay.md) の 086「落ちものパズルのゲーム性」。
- 関連・対立：[risk-or-other-appeal](genre-purpose.md#risk-or-other-appeal)、[difficulty-or-assistance](onboarding-difficulty.md#difficulty-or-assistance)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

<a id="reward-feedback"></a>
## reward-feedback：報酬の量を増やすか、達成と使い道を伝えるか

- 問題：報酬の量を増やすか、達成と使い道を伝えるか。
- 適用状況：進展はあるのに達成が伝わらない、目標が遠い、数値を得ても使う理由がない場面。
- 出典要約：手の届く目標、魅力的な使い道、良い行動を褒める反応、意味を感じるスコア表現を扱う。
  - 出典：[planning.md](../references/planning.md) の 023「目の前に吊られたごほうび」、[gameplay.md](../references/gameplay.md) の 075「ごほうび要素はまっ先に」、[planning.md](../references/planning.md) の 095「ほめてやれ!」、[planning.md](../references/planning.md) の 198「スコアの見せかた」。
- 判断案（編集上の解釈）：量、用途、次の目標、達成時の反応を別々に点検し、本人が進展を説明できるかを見る。
- 適用外・導けないこと：大量の通貨配布だけを解決にしない。数字や称賛が全作品で必要とは断定しない。
- 関連・対立：[progression-rewards](player-experience.md#progression-rewards)、[goal-and-pacing](systems.md#goal-and-pacing)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

## goal-and-pacing：成長に合わせて敵を強くするか、緩急を作るか

- 問題：成長に合わせて敵を強くするか、緩急を作るか。
- 適用状況：成長が無意味に感じられる、難所が連続する、長いプレイ時間だけを売りにしている場面。
- 出典要約：自機と敵の比例的強化による単調さ、難関と平地、反復中に見せる期待、プレイ時間のコストを挙げる。
  - 出典：[gameplay.md](../references/gameplay.md) の 105「単調な坂は山登りにならない」、[gameplay.md](../references/gameplay.md) の 127「やり直しに見合う魅力はあるか？」、[planning.md](../references/planning.md) の 248「いただく時間を意識する」。
- 判断案（編集上の解釈）：遊びの区間ごとに新しい判断、成果の実感、休息を記録する。短縮と変化の追加を目的に応じて比べる。
- 適用外・導けないこと：全ゲームのレベル補正を禁止する根拠にはしない。短いほど良いとも、長さだけで価値が出るとも言えない。
- 関連・対立：[retry-or-consequence](onboarding-difficulty.md#retry-or-consequence)、[reward-feedback](systems.md#reward-feedback)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

## asymmetry-or-balance：性能を均すか、個性を残して調整するか

- 問題：性能を均すか、個性を残して調整するか。
- 適用状況：対戦や戦略のキャラ・装備・ユニット調整。選択に差がない場合と、対処不能の場合を区別する。
- 出典要約：駆け引きの深さ、極端な長短所、相性、多軸の調整、実戦データによる評価を扱う。
  - 出典：[gameplay.md](../references/gameplay.md) の 082「対戦は複雑になるもの?」、[planning.md](../references/planning.md) の 204「パラメーターでキャラ立ちを」、[specs.md](../references/specs.md) の 216「平均と平凡は同じ」、[gameplay.md](../references/gameplay.md) の 228「戦略シミュレーションのゲーム性」、[gameplay.md](../references/gameplay.md) の 245「長所を伸ばし、短所も伸ばす」。
- 判断案（編集上の解釈）：残す強みを一言で決め、威力以外の発生・後隙・範囲等も比較する。相性と利用状況別の成績を見る。
- 適用外・導けないこと：個性を理由に使えない選択肢や回避不能な支配を放置しない。紹介された勝率を全作品の合格線にしない。
- 関連・対立：[randomness-and-handicap](player-experience.md#randomness-and-handicap)、[playtest-evidence](team-decisions.md#playtest-evidence)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

<a id="ai-fairness"></a>
## ai-fairness：CPU を強くするか、人が納得できる振る舞いにするか

- 問題：CPU を強くするか、人が納得できる振る舞いにするか。
- 適用状況：完全反応、完璧な防御、状況によって停止するロジックなどが問題の CPU。
- 出典要約：技のデータと状況を参照し、反応に遅延を持たせ、強い CPU は無敵の防御より攻撃的にする助言がある。
  - 出典：[planning.md](../references/planning.md) の 219「コンピュータープレイヤー」。
- 判断案（編集上の解釈）：狙う相手の腕前と学習目的を決め、反応時間、防御頻度、行動の切替を別々に試す。
- 適用外・導けないこと：勝率だけを目的にしない。全ジャンルの AI 実装方式や一定の遅延値を確定する資料ではない。
- 関連・対立：[difficulty-or-assistance](onboarding-difficulty.md#difficulty-or-assistance)、[asymmetry-or-balance](systems.md#asymmetry-or-balance)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

## customization-preview：選択肢を増やすか、効果を理解して試せるようにするか

- 問題：選択肢を増やすか、効果を理解して試せるようにするか。
- 適用状況：装備・能力・外見のカスタマイズで、選ぶ楽しさや変更後の効果が伝わらない場面。
- 出典要約：効果の可視化、極端な長短所、選びやすさ、その場での試用、かっこよさを挙げる。
  - 出典：[planning.md](../references/planning.md) の 180「カスタマイズは想像で遊ぶ」。
- 判断案（編集上の解釈）：見た目の選択と性能の選択を分け、選ぶ前後の予測と体験が一致するかを確認する。
- 適用外・導けないこと：外見だけの着せ替えに性能差を強制しない。装備数の増加だけで選択の深さを保証しない。
- 関連・対立：[progression-rewards](player-experience.md#progression-rewards)、[asymmetry-or-balance](systems.md#asymmetry-or-balance)。

<a id="guided-or-free-route"></a>
## guided-or-free-route：解法を教えるか、攻略の自由を残すか

- 問題：解法を教えるか、攻略の自由を残すか。
- 適用状況：おつかい、ボス、謎解きで、目的の不明瞭さと手順の強制感を区別する。
- 出典要約：おつかいは適切な報酬、短い喜び、ルートの自由、帰路の扱い、期待を設計する。ボスの固定解法と自由攻略に唯一の正解はない。
  - 出典：[planning.md](../references/planning.md) の 064「良いおつかい、悪いおつかい」、[gameplay.md](../references/gameplay.md) の 217「強制感と攻略バランス」。
- 判断案（編集上の解釈）：目的と制約を理解できるかを先に確かめ、解法発見を楽しませたい場面と反復攻略を分ける。
- 適用外・導けないこと：自由度だけを理由に全ての誘導を消さない。解法を限定する狙いを聞かず、欠陥と決めない。
- 関連・対立：[tutorial-or-practice](onboarding-difficulty.md#tutorial-or-practice)、[reward-feedback](systems.md#reward-feedback)。
- 根拠の状態：AI 要約のみ・原動画未照合。条件の整理と比較手順は編集上の解釈。

## original-or-familiar：既存作品で説明するか、独自の魅力を定義するか

- 問題：既存作品で説明するか、独自の魅力を定義するか。
- 適用状況：学習用の模作、チーム内の比喩、製品の差別化、初回の企画説明。
- 出典要約：面白さの分解・考察・再構築と、比較対象にない魅力を積むことを勧める。共有できる相手への比喩は例外として認める。
  - 出典：[planning.md](../references/planning.md) の 057「分解､考察､再構築」、[planning.md](../references/planning.md) の 159「あるものでしかわからない」、[planning.md](../references/planning.md) の 194「同じような作品」、[misc.md](../references/misc.md) の 072「過去との競争」。
- 判断案（編集上の解釈）：似ていると言う部分を機能と体験に分解し、残す理由と独自に変える部分を示す。学習段階と製品化を分ける。
- 適用外・導けないこと：全ての比喩や模作を禁止しない。他作品の表面を混ぜただけで独創性を証明したことにしない。
- 関連・対立：[risk-or-other-appeal](genre-purpose.md#risk-or-other-appeal)、[market-data-or-concept](planning-practice.md#market-data-or-concept)。

## sequel-or-new：前作を引き継ぐか、新しい核を作るか

- 問題：前作を引き継ぐか、新しい核を作るか。
- 適用状況：続編・再利用の判断。前作の体験と開発資産の両方を確認できる場合。
- 出典要約：続編はシステムとツールを使える反面、前作を超える魅力への投資が要る。作品ごとの環境やチームが大規模構想の成立条件となる。
  - 出典：[planning.md](../references/planning.md) の 162「続編のありかた」、[concepts.md](../references/concepts.md) の 040「大乱闘スマッシュブラザーズDX」、[concepts.md](../references/concepts.md) の 158「大乱闘スマッシュブラザーズSPECIAL」。
- 判断案（編集上の解釈）：既存ファンがまだ欲しい体験、再利用できるもの、新しい負担を分けて比較する。
- 適用外・導けないこと：売上が半分という表現を個別作品の予測式にしない。別のチームでも同じ規模を再現できるとは限らない。
- 関連・対立：[scope-or-quality](production.md#scope-or-quality)、[original-or-familiar](systems.md#original-or-familiar)。

## ranking-or-belonging：順位を競わせるか、参加と上達を感じさせるか

- 問題：順位を競わせるか、参加と上達を感じさせるか。
- 適用状況：ランキング、対戦人口、観戦の動機を扱う設計。
- 出典要約：順位は目標とマッチングの手がかりになる一方、下位の意欲を失わせる。観戦では肩入れできる動機が盛り上がりに関わる。
  - 出典：[gameplay.md](../references/gameplay.md) の 168「ランキングの功罪」、[planning.md](../references/planning.md) の 119「応援する楽しみ」。
- 判断案（編集上の解釈）：熟練者の競争と新規参加の入口を分け、自分の上達を感じる表示と対戦成立率を確認する。
- 適用外・導けないこと：一つのランキング方式を万能としない。観戦の賭け表現を、そのまま別地域へ実装する指示にしない。
- 関連・対立：[randomness-and-handicap](player-experience.md#randomness-and-handicap)、[reward-feedback](systems.md#reward-feedback)。

## exploit-or-bug：抜け道を残すか、不具合として直すか

- 問題：抜け道を残すか、不具合として直すか。
- 適用状況：ゲーム内の稼ぎや攻略の工夫と、進行破壊・外部改変・他者への影響を分ける。
- 出典要約：ゲーム内でできる得な攻略を全て潰さない助言と、致命的不具合の修正、更新コスト、初回体験への配慮がある。
  - 出典：[gameplay.md](../references/gameplay.md) の 048「ズルを許す」、[specs.md](../references/specs.md) の 229「オンラインアップデート」。
- 判断案（編集上の解釈）：誰が利益・損失を受けるか、戻せるか、他の遊びを無意味にするかを確認して残す範囲を決める。
- 適用外・導けないこと：ズルを許すをオンラインの不正やセーブ破損の放置に一般化しない。外部改変の可否は所有者の規則も確認する。
- 関連・対立：[exhaustive-or-targeted](production.md#exhaustive-or-targeted)、[asymmetry-or-balance](systems.md#asymmetry-or-balance)。
