# 決定カードの形式

一つのカードで一つの意思決定を扱う。複数の選択肢の比較は同じカードに置き、片方だけが検索される誤用を避ける。番号とタイトルは既存の参照ファイルの見出しと照合する。

```markdown
## 一意の ID：決めたい問い

- 問題：どの判断を支援するか。
- 適用状況：工程・目的・制約。資料の明記と編集上の推定を区別する。
- 出典要約：資料が述べている内容。出典ファイル・通し番号・タイトルを添える。
- 判断案（編集上の解釈）：適用する条件と、その条件で勧める行動。
- 適用外・導けないこと：別の意思決定への飛躍、未確認の例外、一般化の限界。
- 関連・対立：比較する別カードまたは別の出典見出し。
- 根拠の状態：AI 要約のみ、または原動画の照合範囲と確認先。
```

要約しか読んでいなければ「AI 要約のみ・原動画未照合」とする。原動画を確認した場合も、確認した箇所だけを確認済みとし、カード全体や全資料へ広げない。
元の要約で分からない適用条件は「不明」と書く。判断案の具体的な時間・予算・実験方法を出典の数値に見せない。

追加後はカード ID のアンカーを設け、[索引](INDEX.md) と主ファイルの分野への入口を確認する。[出典分類](COVERAGE.md) と `coverage.json` は本文で引用した番号と一致させる。分類は主張の正しさを保証せず、元の見出しと本文の確認を置き換えない。

条件を変えた入力を [評価ケース](../evaluation/expanded-cases.md) に追加し、`evaluation/card-coverage.json` で対象カードと結び付ける。背景資料から新しくカード化するときは、背景の保存理由も再検討する。
